# 출시 전 확인 목록

실제 판매·광고 집행 전에 확인해야 할 제품·운영 정보입니다. 화면에는 '출시 전 확인 중'으로 표시하거나 아예 쓰지 않았습니다.
확인되면 `src/i18n/dict/*.ts`(문구)와 `src/data/commerce.ts`(가격·배송)를 고칩니다.

| 기준가 | 42,000원(취소선) | 실제 판매 이력이 없으면 '종전 가격'처럼 보이는 취소선 표기가 표시·광고 기준에 맞는지 검토 |
| 첫 구매 혜택가 | 35,000원 | 현재 방침: 모든 주문이 첫 구매이므로 수량과 관계없이 전체 수량에 적용(2026-10-27 결정). 실제 운영 시 첫 구매 판별 방식(회원·주문 이력) 필요 |

## 아직 자료가 없는 항목 — 추측해서 쓰지 않음

- 전성분(화장품법에 따른 전 성분 표기). 기획 문서의 성분 설계는 포트폴리오용 가상 설정이라 쓰지 않았습니다.
- 기능성 화장품 심사·보고 여부. 확인 전까지 '미백 기능성' 표현을 쓰지 않았습니다.
- 인체적용시험 등 시험 결과. 기획 문서의 피부 밝기·광택도 등 수치는 가상 수치라 쓰지 않았습니다.
- 화장품제조업자 · 화장품책임판매업자 상호와 주소
- 사용기한 또는 개봉 후 사용기간, 피부 타입, 사용 시 주의사항, 품질보증기준, 소비자상담 전화번호
- 1회 사용량과 사용 주기
- 제품 정식 명칭(국문·영문), MORH·모르 상표 검색

## 운영 정책

- 교환·환불: 반품 배송비, 반품 주소, 처리 기간, 문의처. 화면에는 전자상거래법 제17조·제18조의 일반 기준만 안내했습니다.
- 사업자 정보(상호, 대표자, 사업자등록번호, 통신판매업 신고번호, 주소, 연락처)
- 개인정보: 운영 주체, 개인정보 보호책임자, 시행일. 실제 수집을 시작하면 수집 항목·목적·보유 기간·파기·위탁·제3자 제공을 다시 작성
- 분석 도구: GA4 를 붙이면 개인정보 처리 안내의 방문 통계 항목이 자동으로 바뀌지만, 쿠키 동의 방식과 보관 기간은 따로 결정
